# Confidentialité — MushafPlus

MushafPlus fonctionne sans compte utilisateur. Les préférences et la position de lecture sont stockées dans le navigateur. Les favoris, notes et données de mémorisation utilisent également le stockage local du navigateur et peuvent être protégés par une phrase secrète lorsque cette option est activée.

La géolocalisation n’est demandée qu’après activation explicite des horaires de prière. Elle sert au calcul local et n’est pas enregistrée par MushafPlus.

Le texte coranique, les traductions, les horaires et l’audio peuvent être chargés depuis des API et CDN tiers. Ces fournisseurs reçoivent les informations réseau nécessaires au traitement d’une requête web et appliquent leurs propres politiques.

Les données locales peuvent être effacées depuis les réglages de l’application ou les outils de stockage du navigateur. MushafPlus n’effectue pas de synchronisation cloud en arrière-plan.

Pour signaler un problème : <https://github.com/mohamedeyaf820/mon-coran/issues>
