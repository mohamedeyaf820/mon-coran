# Sources et composants tiers

MushafPlus peut utiliser les services et ressources suivants selon la fonctionnalité demandée :

- Quran.com API et AlQuran Cloud : texte, mots, traductions et métadonnées coraniques ;
- Quran.com Audio, EveryAyah, MP3Quran, QuranicAudio et Islamic Network CDN : récitations ;
- Quran.com, Quran Foundation et Quran Word by Word : polices et ressources coraniques ;
- React, Vite, Radix UI, Lucide et autres dépendances listées dans `package.json` : interface et outillage.

Les marques, textes, fichiers audio, polices, images et bibliothèques restent soumis aux droits et licences de leurs propriétaires. Ce document décrit les sources techniques ; il ne transfère aucun droit sur leurs contenus.

Le dépôt ne contient actuellement pas de fichier déclarant une licence générale de redistribution du code MushafPlus.
